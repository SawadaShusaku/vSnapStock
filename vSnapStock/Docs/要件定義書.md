# vSnapStock 要件定義書

## 1. 概要・コンセプト

Google Keep風の写真付きカード管理アプリ。食料品の在庫管理や賞味期限管理を主な用途とし、写真とメモで視覚的に管理できる。

## 2. 対応環境

| 項目 | 内容 |
|------|------|
| 対応OS | iOS 18.0 以上 |
| 対応デバイス | iPhone（優先）、iPad（余裕があれば） |
| 開発言語 | Swift 6 |
| UIフレームワーク | SwiftUI |

## 3. データモデル

### Card（カード）

| プロパティ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| id | UUID | ○ | 一意識別子 |
| title | String | - | タイトル（最大40文字） |
| description | String | - | 説明文（最大1000文字） |
| photos | [Data] | - | 写真データ（最大10枚、圧縮保存） |
| expirationDate | Date? | - | 賞味期限 |
| useByDate | Date? | - | 消費期限 |
| createdAt | Date | ○ | 作成日時（自動） |
| updatedAt | Date | ○ | 更新日時（自動） |
| isArchived | Bool | ○ | アーカイブ状態 |
| isDeleted | Bool | ○ | ゴミ箱状態 |
| deletedAt | Date? | - | 削除日時（7日後に完全削除） |
| sortOrder | Int | ○ | 並び順（手動並び替え用） |
| tags | [Tag] | - | タグ（将来実装） |

### Tag（タグ）※将来実装

| プロパティ | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| id | UUID | ○ | 一意識別子 |
| name | String | ○ | タグ名 |
| color | String | - | タグの色 |

## 4. 画面一覧

### 4.1 ホーム画面（メイン）
- 2列グリッドでカード一覧を表示
- デフォルト並び順：更新日時順（新しい順）
- 手動並び替え対応（ドラッグ&ドロップ）
- スワイプ操作：左→削除、右→アーカイブ
- タップ→詳細/編集画面へ遷移

**UI要素：**
- 右下：追加ボタン（+）
- 右上：3点メニューボタン
- 右上（3点の左）：検索ボタン

### 4.2 カード追加/編集シート
- 写真サムネイル表示エリア（複数枚対応）
- タイトル入力欄
- 説明入力欄
- 賞味期限入力（DatePicker）
- 消費期限入力（DatePicker）

### 4.3 写真追加シート
- 上半分：カメラプレビュー
- 中央：撮影済み写真サムネイル一覧
- 下部：フラッシュ / シャッター / アルバムボタン

### 4.4 アーカイブ画面
- アーカイブ済みカードの一覧表示
- 復元・完全削除が可能

### 4.5 ゴミ箱画面
- 削除済みカードの一覧表示
- 7日経過で自動完全削除
- 復元・即時完全削除が可能

### 4.6 設定画面
- 項目は後日決定

## 5. 機能詳細

### 5.1 検索機能
- 検索対象：タイトル、説明文
- マッチ方式：部分一致
- 表示：ホーム画面をそのまま絞り込み表示

### 5.2 同期機能（自動）
- SwiftData + CloudKit による自動同期
- 別デバイスでもiCloudアカウントが同じなら自動でデータ共有
- 設定でオン/オフ切り替え可能（将来実装）

### 5.3 期限通知・表示（優先度：低）
- 期限切れ/期限間近のカードを色で強調表示
- 設定でオン/オフ切り替え可能

### 5.4 ゴミ箱機能
- 削除→即時ゴミ箱へ移動
- 7日後に自動完全削除
- 手動で復元・完全削除可能

## 6. 3点メニュー項目

1. アーカイブ一覧
2. ゴミ箱
3. 設定

## 7. 使用フレームワーク・ライブラリ

### データ永続化
| 用途 | 技術 |
|------|------|
| ローカルDB + iCloud同期 | **SwiftData** (`@Model`, `ModelContainer`, `ModelConfiguration(cloudKitDatabase: .automatic)`) |

### UI
| 用途 | 技術 |
|------|------|
| レイアウト | SwiftUI (`LazyVGrid`, `ScrollView`) |
| シート | `.sheet()`, `.fullScreenCover()` |
| 日付選択 | `DatePicker` |
| ドラッグ並び替え | `.onMove()`, `EditMode` or カスタム実装 |
| スワイプアクション | `.swipeActions()` |
| 検索バー | `.searchable()` |
| メニュー | `Menu` + `Button` |

### カメラ・写真
| 用途 | 技術 |
|------|------|
| カメラ撮影 | **AVFoundation** (`AVCaptureSession`, `AVCapturePhotoOutput`) |
| 写真選択 | **PhotosUI** (`PhotosPicker`) |
| 画像圧縮 | `UIImage.jpegData(compressionQuality:)` |

### その他
| 用途 | 技術 |
|------|------|
| ローカル通知 | **UserNotifications** (`UNUserNotificationCenter`) ※期限通知用 |
| バックグラウンド処理 | `BackgroundTasks` ※ゴミ箱自動削除用 |

## 8. 優先度

### MVP（最小実装）
1. ホーム画面（カード一覧表示）
2. カード追加/編集
3. 写真撮影・選択
4. SwiftData保存（iCloud自動同期込み）
5. スワイプ削除・アーカイブ
6. アーカイブ画面
7. ゴミ箱画面（7日自動削除）

### Phase 2
1. 検索機能
2. 手動並び替え（ドラッグ&ドロップ）
3. 期限表示の色分け

### Phase 3（将来）
1. タグ機能
2. 期限通知（プッシュ通知）
3. iPad対応
4. その他独自機能

```
  └─ [3点メニュー]

       ├─ ゴミ箱 → ゴミ箱画面

```
